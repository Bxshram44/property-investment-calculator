# 🏠 Property Investment Calculator

A Python and Streamlit web application that allows users to analyse and compare potential property investments.

I built this project to develop my Python programming skills while applying them to a real-world financial scenario. The calculator takes property, mortgage and expense information and calculates key investment metrics.

## Features

- Calculate gross rental yield
- Calculate repayment and interest-only mortgage payments
- Calculate monthly and annual cash flow
- Calculate cash-on-cash return
- Include maintenance, insurance and management expenses
- Include additional purchase or renovation costs
- Compare multiple properties
- Identify the property with the best:
  - Gross rental yield
  - Monthly cash flow
  - Cash-on-cash return
- Input validation for property and mortgage information
- Interactive web interface built with Streamlit

## Technologies Used

- Python
- Streamlit
- Git
- GitHub
- Visual Studio Code

## How It Works

The user enters information including:

- Property price
- Deposit percentage
- Monthly rental income
- Mortgage interest rate
- Mortgage term
- Mortgage type
- Monthly property expenses
- Additional purchase or renovation costs

The application then calculates and displays key investment metrics to help compare different properties.

## Running the Project

Install the required dependency:

```bash
pip install streamlit
```

Then run:

```bash
python -m streamlit run app.py
```
